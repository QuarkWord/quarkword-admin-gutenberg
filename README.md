# QuarkPress Admin Gutenberg

A Quarkus extension that serves QuarkPress's admin screens under each site's admin path: a small admin shell (sign-in
through OpenID Connect, the posts, pages and media lists, trash and restore) and WordPress's own block editor, loaded
from WordPress's built packages and working on QuarkPress's WordPress-compatible REST API. Licensed under the GNU
General Public License, version 2 or later.

Status: in progress.
